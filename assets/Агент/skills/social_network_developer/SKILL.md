## 📋 ОПИСАНИЕ

Шелдон проектирует и разрабатывает собственную социальную сеть — платформу для сообщества проекта «Собачья мудрость». Соцсеть ориентирована на людей, любящих собак, и на сообщество единомышленников.

**Ключевой принцип:** Доступность для людей с нарушениями опорно-двигательного аппарата и нервными заболеваниями. Никакого drag-and-drop, резких звуков и движений.

---

## 🎯 КОНЦЕПЦИЯ

### Название (рабочее)
**PawWisdom** или **DogWisdom Network** — уточняется

### Миссия
Создать тёплое, безопасное пространство, где люди делятся историями о собаках, находят поддержку, вдохновляются «собачьей мудростью».

### Целевая аудитория
- Владельцы собак
- Люди, пережившие потерю питомца
- Люди с ОДА и нервными заболеваниями (приоритет!)
- Фрилансеры и творческие люди
- Читатели проекта «Собачья мудрость»

### Уникальность
- Философия «собачьей мудрости» как основа контента
- Максимальная доступность (accessibility-first)
- Тёплая, ненавязчивая атмосфера
- Интеграция с проектами: Dream Team, Libryt, «Собачья мудрость»

## ♿ ДОСТУПНОСТЬ (ПРИОРИТЕТ!)

### Обязательные требования

1. **Навигация с клавиатуры** — всё доступно через Tab, Enter, Escape
2. **Screen reader совместимость** — ARIA-лейблы, семантический HTML
3. **Нет drag-and-drop** — все действия через клики и кнопки
4. **Нет резких анимаций** — плавные переходы, отключаемые
5. **Нет автовоспроизведения** — видео/аудио только по клику
6. **Контрастность** — минимум WCAG AA (4.5:1)
7. **Размер шрифта** — масштабируемый, минимум 16px
8. **Фокус** — видимый индикатор фокуса на всех интерактивных элементах
9. **Формы** — все поля с лейблами, ошибки описаны текстом
10. **Таймеры** — никаких ограничений по времени на действия

### Дополнительно

- Режим «для нервных» — отключение уведомлений, звуков, анимаций
- Простой режим — минимум визуального шума
- Поддержка switch-устройств и eye-tracking

## 🗄️ МОДЕЛЬ ДАННЫХ (основные сущности)

### User (Пользователь)
```
- id: UUID
- username: string (уникальный)
- email: string (уникальный)
- display_name: string
- avatar_url: string?
- bio: string?
- role: enum [user, moderator, admin]
- created_at: datetime
- updated_at: datetime
- settings: JSON (настройки доступности, уведомлений)
```

### Post (Пост)
```
- id: UUID
- author_id: User.id
- content: string (до 5000 знаков)
- media_urls: string[]
- hashtags: string[]
- likes_count: int
- comments_count: int
- created_at: datetime
- updated_at: datetime
```

### Comment (Комментарий)
```
- id: UUID
- post_id: Post.id
- author_id: User.id
- parent_id? Comment.id (для древовидности)
- content: string (до 1000 знаков)
- created_at: datetime
```

### Follow (Подписка)
```
- follower_id: User.id
- following_id: User.id
- created_at: datetime
```

### Notification (Уведомление)
```
- id: UUID
- user_id: User.id
- type: enum [like, comment, follow, mention]
- source_user_id: User.id
- post_id? Post.id
- read: boolean
- created_at: datetime
```

### Pet (Питомец — профиль собаки)
```
- id: UUID
- owner_id: User.id
- name: string
- breed: string?
- birth_date: date?
- photo_url: string?
- bio: string?
- created_at: datetime
```

## 🔒 БЕЗОПАСНОСТЬ

1. **Аутентификация** — NextAuth.js с JWT + refresh tokens
2. **Авторизация** — RBAC (user, moderator, admin)
3. **Валидация** — Zod на всех входах
4. **Rate limiting** — защита от спама
5. **CORS** — строгая политика
6. **CSP** — Content Security Policy заголовки
7. **SQL-инъекции** — Prisma ORM защищает по умолчанию
8. **XSS** — React экранирует + CSP
9. **CSRF** — токены для форм
10. **Модерация контента** — фильтрация спама, жалобы пользователей

## 📊 МАСШТАБИРОВАНИЕ

### Начальный этап (до 1000 пользователей)
- 1 VPS (4 vCPU, 8 GB RAM)
- PostgreSQL на том же сервере
- Redis на том же сервере
- Стоимость: ~€5/мес

### Рост (1000-10000 пользователей)
- Отдельный сервер БД
- CDN для статики
- Кэширование ленты в Redis
- Стоимость: ~€20-50/мес

### Зрелость (10000+ пользователей)
- Микросервисная архитектура
- Кластер PostgreSQL
- Очереди сообщений (RabbitMQ)
- Мониторинг (Grafana + Prometheus)
- Стоимость: ~€100+/мес
